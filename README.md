# شاشة أسعار العملات المباشرة

واجهة عرض عربية للصرافة تحتوي على فيديو كبير وشريط أسعار ثابت ومتحرك أسفل الشاشة.

## التشغيل

1. ثبّت Node.js 22 أو أحدث.
2. افتح مجلد المشروع وشغّل `npm install`.
3. شغّل `npm run dev` ثم افتح الرابط الذي يظهر لك.

## مصدر الأسعار

- الواجهة تطلب `/api/rates` كل 10 ثوانٍ مع إضافة وقت متغير لمنع الكاش.
- الخادم يحاول قراءة الملف المباشر من ClearView أولًا.
- عند تعذر المصدر المباشر يستخدم `public/rateswithcss.xml` تلقائيًا.
- لتغيير رابط المصدر عدّل `LIVE_RATES_URL` في `app/api/rates/route.ts`.

## الفيديو

يمكن اختيار فيديو من زر «اختر فيديو العرض» داخل الصفحة. ولجعل فيديو ثابتًا بشكل دائم، ضع رابط الفيديو في `DEFAULT_VIDEO` داخل `app/page.tsx` أو استبدله بمسار ملف داخل مجلد `public`.
